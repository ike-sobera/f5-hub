O Conceito: O Diretor e o Ator

Imagine que você é um diretor de cinema. Você achou o cenário perfeito, a luz perfeita e a pose perfeita em uma foto (Pinterest, Behance, um meme). Mas você precisa que o seu cliente seja a estrela dessa cena.

Como a mágica acontece

Nós não vamos pedir para a IA "desenhar algo parecido". Vamos usar um fluxo profissional de extração. Nós "roubamos" apenas a luz, a pose e o cenário (o Blueprint) e jogamos o nosso cliente lá dentro, removendo os textos e bagunças da imagem original.

Passo 2 de 6

A Imagem de Referência

Primeiro, você precisa de uma imagem que tenha exatamente a "vibe" que você quer para a Landing Page ou anúncio.

O que importa na foto:

A posição dos braços, a inclinação da cabeça, as sombras, as cores do ambiente e o clima da cena.

O que NÃO importa:

A identidade da pessoa, o cabelo, a roupa e até mesmo textos ou logos espalhados pela foto (vamos arrancar tudo isso!).

Salve a Imagem

Baixe sua referência no Pinterest e deixe salva no seu PC. Vamos usá-la no próximo passo.

Passo 3 de 6

A Extração do Blueprint (JSON)

Chegou a hora de transformar aquela imagem em dados puros. Vá até o Claude ou ChatGPT e anexe a foto de referência que você escolheu.

Atenção ao copiar!

O texto abaixo é um super prompt técnico. Apenas copie, cole junto com a foto de referência e aperte Enter. A IA vai te devolver um código JSON complexo.

Prompt de Extração de Cena 
EXTRAÇÃO PROFISSIONAL DE JSON CINEMATOGRÁFICO PARA IA DE IMAGEM

Analise a imagem enviada e gere um JSON cinematográfico EXTREMAMENTE DETALHADO e ESTRUTURADO.
O objetivo NÃO é descrever a pessoa da imagem.
O objetivo é extrair:
composição
pose
iluminação
câmera
ambiente
direção de arte
narrativa visual
cinematografia
para que posteriormente outra ferramenta possa substituir completamente a identidade da pessoa usando uma nova imagem de referência.

CONTEXTO DO WORKFLOW
Fluxo real:
1. Uma imagem é enviada apenas para EXTRAÇÃO do JSON
2. Depois, em outra ferramenta:
o JSON será reutilizado
uma NOVA foto de pessoa será anexada
3. A nova ferramenta irá:
usar o JSON como blueprint cinematográfico
usar a nova foto apenas para rosto e roupa
Portanto:
A PESSOA ORIGINAL NÃO É CANÔNICA
A composição é canônica.
A cinematografia é canônica.
A pose é canônica.
A identidade NÃO.

OBJETIVO PRINCIPAL
Criar um JSON que funcione como:
blueprint visual reutilizável
molde cinematográfico
estrutura de direção de arte
composição procedural
base para identity replacement
O JSON deve preservar:
pose
câmera
iluminação
ambiente
blocking
profundidade
narrativa visual
emoção da cena
permitindo substituir:
rosto
cabelo
etnia
roupa
identidade

ESTRUTURA OBRIGATÓRIA
O JSON deve SEMPRE conter:
objective
format
identity_replacement_rules
reference_priority
scene
subject_pose
composition
lighting
environment
visual_style
camera_direction
emotional_tone
strict_removals
negative_prompt

REGRAS CRÍTICAS
1. IDENTIDADE NÃO É FIXA
A imagem original NÃO deve definir: rosto, cabelo, roupa, etnia, identidade visual.
O JSON deve tratar o sujeito original apenas como placeholder.

2. EXTRAIR APENAS A DIREÇÃO DE ARTE
Focar em: pose, câmera, cinematografia, ambiente, iluminação, profundidade.

3. SUBJECT PLACEHOLDER RULE
O JSON deve deixar explícito: original_subject_is_placeholder_only.

4. IDENTITY REPLACEMENT RULES
Conter: replace_subject_identity: true, replace_face: true, etc.

5. WARDROBE FLEXIBILITY
Permitir troca completa de figurino sem quebrar pose.

6. DESCREVER A POSE COM EXTREMA PRECISÃO
Cabeça, braços, tensão corporal, distribuição de peso. NUNCA identidade facial.

7. COMPOSIÇÃO, ILUMINAÇÃO, AMBIENTE E ESTILO
Detalhar ao extremo: câmera, luz, sombras, objetos, atmosfera.

11. REMOVER ELEMENTOS GRÁFICOS
Remover: textos, logos, UI, marcas d’água, stickers. Preservando o ambiente limpo.

12. NEGATIVE PROMPT AGRESSIVO
Bloquear: different composition, original face retention, bad anatomy, text, logos, etc.

13. QUALIDADE DO RESULTADO
A saída deve parecer documentação de pipeline de direção de arte para IA.
NÃO simplifique. NÃO resuma. Quero um JSON técnico e altamente detalhado.
Passo 4 de 6

A Foto do Cliente

O Claude te devolveu o código JSON. Excelente! Agora você precisa da foto de quem vai "atuar" nessa cena.

Escolha a foto certa

A foto do cliente não precisa ter o fundo perfeito (nós vamos descartá-lo). Mas o rosto precisa estar visível, em uma resolução bacana. Esta foto será a nossa Identidade Absoluta.
