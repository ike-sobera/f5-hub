Passo 1 de 10

Recepção e Análise do Pedido

Tudo começa quando recebemos o pedido da Landing Page (LP). Antes de sair criando, precisamos entender o cenário.

O que fazer aqui?

O erro mais comum é começar a desenhar sem saber o objetivo. É para capturar leads (contatos)? É para vender um produto direto? É para um evento?

  • Leia todo o material (textos, referências).
  • Verifique se os textos fazem sentido para o objetivo.
  • Se faltar alguma coisa (logo, texto de botão), pergunte agora. Não deixe para depois!
Passo 2 de 10

Curadoria e Tratamento (A Base)

Essa é a parte que exige um pouco mais de mão na massa (e paciência), mas é o que garante que o site vai carregar rápido e ficar bonito.

1. Preparar Imagens

Pegue todas as fotos e logotipos. Remova o fundo das imagens que precisam e corte nos tamanhos certos. Evite imagens "pesadas".

2. Formato WebP

Converta as imagens para o formato WebP. Esse é o segredo para o site abrir em um piscar de olhos no celular do cliente.

Passo Crucial para a IA

Crie uma pasta na nuvem (Google Drive, por exemplo), coloque todas essas imagens prontas lá dentro e copie o link de compartilhamento. A Inteligência Artificial vai precisar desse link no próximo passo!

Passo 6 de 10

Ajuste Fino (O Toque Humano)

A IA levanta o prédio, mas você é quem faz a decoração de interiores. Esse é o momento onde o design da f5 ganha vida e personalidade.

Respiros (Espaçamento)

A IA costuma espremer as coisas. Aumente as margens entre as seções. O design premium precisa de "ar" para respirar.

Tipografia (Letras)

Ajuste os tamanhos. Títulos grandes e chamativos, textos de leitura com tamanho confortável (nunca menor que 16px no celular).

Revisão Mobile

Diminua a tela e veja se nada quebrou. Botões devem ser grandes o suficiente para um dedo clicar sem errar.

Economia de Créditos

Use a IA do Antigravity apenas para arrumar pequenos erros técnicos. O design visual (cores e espaços) faça com o mouse para poupar os créditos da agência.

Colando o Código da f5

Na tela que abriu, apague tudo que estiver escrito lá e cole exatamente este código abaixo:

Código Apps Script 
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

  // 1. Captura dinâmica de dados
  const dataAtual = new Date();
  const nome = e.parameter.nome || 'Não informado';
  const email = e.parameter.email || 'Não informado';
  const telefone = e.parameter.telefone || 'Não informado';
  const plano = e.parameter.plano || 'Não informado';
  const mensagem = e.parameter.mensagem || 'Nenhuma mensagem';

  // 2. Registro na Planilha
  sheet.appendRow([dataAtual, nome, email, telefone, plano, mensagem]);

  // 3. Estrutura Visual f5 (HTML Dark Mode)
  const htmlBody = `
  <!DOCTYPE html>
  <html>
  <head>
  <style>
    body { font-family: 'Inter', sans-serif; background-color: #0A0A0A; margin: 0; padding: 40px 20px; }
    .container { max-width: 600px; margin: 0 auto; background-color: #141414; color: #F5F5F5; border-radius: 12px; border: 1px solid #2E2E2E; overflow: hidden; }
    .header { padding: 30px 40px; border-bottom: 1px solid #2E2E2E; background: linear-gradient(135deg, #141414 0%, #1e110d 100%); }
    .logo-img { max-width: 50px; height: auto; margin-bottom: 16px; display: block; border-radius: 8px; }
    .header h1 { margin: 0; font-size: 24px; font-weight: 600; color: #FFFFFF; letter-spacing: -0.5px; }
    .content { padding: 40px; }
    .field { margin-bottom: 24px; }
    .label { font-size: 11px; color: #8A8A8A; text-transform: uppercase; letter-spacing: 1px; margin-bottom: 8px; font-weight: 600; }
    .value { font-size: 15px; color: #E0E0E0; background-color: #1A1A1A; padding: 14px 18px; border-radius: 8px; border: 1px solid #2E2E2E; }
    .footer { padding: 30px 40px; background-color: #141414; border-top: 1px solid #2E2E2E; text-align: center; }
    .btn { display: block; width: 100%; box-sizing: border-box; background-color: #F25621; padding: 16px 0; font-size: 14px; font-weight: 600; border-radius: 8px; text-transform: uppercase; letter-spacing: 1px; text-align: center; text-decoration: none; color: #ffffff !important; }
  </style>
  </head>
  <body>
    <div class="container">
      <div class="header">
        <img src="LINK_DA_LOGO_F5.png" alt="f5" class="logo-img">
        <h1>Novo Lead Capturado</h1>
      </div>
      <div class="content">
        <div class="field"><div class="label">Nome Completo</div><div class="value">${nome}</div></div>
        <div class="field"><div class="label">E-mail</div><div class="value">${email}</div></div>
        <div class="field"><div class="label">WhatsApp</div><div class="value">${telefone}</div></div>
        <div class="field"><div class="label">Projeto/Plano</div><div class="value">${plano}</div></div>
      </div>
      <div class="footer">
        <a href="https://wa.me/55${telefone.replace(/\D/g, '')}" class="btn">INICIAR CONVERSA NO WHATSAPP</a>
      </div>
    </div>
  </body>
  </html>
  `;

  // 4. Configuração de Envio
  const emailDestino = "cliente@exemplo.com";
  const assuntoEmail = `[f5 Lead] 🍊 ${nome} - ${plano}`;

  MailApp.sendEmail({
    to: emailDestino,
    subject: assuntoEmail,
    htmlBody: htmlBody
  });

  return ContentService.createTextOutput("Sucesso");
}

Atenção: Role até o final do código e encontre a linha const emailDestino = "cliente@exemplo.com";. Altere esse e-mail para o e-mail verdadeiro de quem vai receber os leads!

3

Implantar e Autorizar

No canto superior direito, clique no botão azul Implantar e depois em Nova implantação.

  • Selecione o tipo App da Web (ícone de engrenagem).
  • Em "Quem pode acessar", mude para Qualquer pessoa.
  • Clique em Implantar.

O Google vai pedir uma autorização de segurança chata. Clique em "Revisar permissões", escolha sua conta, clique em Avançado lá embaixo e depois em "Acessar projeto (não seguro)".

4

Conectando o Webhook

O Google vai gerar uma URL longa ("URL do app da Web"). Copie esse link.
Volte para o Antigravity, clique nas configurações do seu Formulário, procure o campo "Webhook" e cole o link lá. Pronto! O caminho está feito.

Passo 8 de 10

Versionamento (GitHub)

O site está pronto e funcionando perfeitamente no construtor. Agora precisamos salvar isso de forma segura.

O nosso "Pen Drive" da Nuvem

Exportamos todos os arquivos da página e subimos para o GitHub. Criamos um repositório privado (uma pasta com cadeado).

Por que fazemos isso? Se o computador de alguém quebrar ou se precisarmos reverter uma alteração no futuro, o código fonte original está salvo, seguro e acessível para toda a equipe f5.

Passo 9 de 10 (Automatizado)

Vercel e Subdomínio

Chegou a hora de tirar a página dos bastidores e colocar na internet de verdade para o mundo ver!

Entramos na Vercel, conectamos aquela pasta do GitHub (Passo 8) e apertamos "Deploy". A Vercel lê os arquivos e cria o site na internet em poucos segundos.

Como nosso sistema de DNS (endereços) já está automatizado, não precisamos quebrar a cabeça. É só ir na Vercel e digitar o nome do cliente antes do nosso domínio padrão.
